# SkillSwap - Creator Gig Marketplace

> **Hackathon ID:** AZIS-5V88EX

A modern, responsive creator gig marketplace built to empower young creators to monetize their skills and allow clients to seamlessly browse, book, and track services.

---

## Track & Category
* **Track:** Creator Economy
* **Project Name:** SkillSwap

---

## Tech Stack
* **Frontend:** HTML5, CSS3 (Modern Glassmorphism Design System)
* **Logic / Scripting:** Pure Vanilla JavaScript (ES6+)
* **State Management & Persistence:** Browser `localStorage` API
* **Deployment:** GitHub Pages

---

## Features Implemented
1. **Post a Gig:** Creators can list services with title, category, rate in Indian Rupees (₹), and description.
2. **Browse & Search:** Real-time search filter by title or category across all available marketplace listings.
3. **Book a Gig:** Clients can submit booking requests with custom project notes.
4. **Creator Dashboard:** Creators can review incoming booking requests and accept or decline them in real time.
5. **My Bookings:** Clients can view their booking history alongside live status updates (Pending, Accepted, Declined).

---

## Local Run Instructions
1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (Google Chrome, Firefox, Safari, Edge).
3. No build steps, `npm install`, or backend dependencies are required.
